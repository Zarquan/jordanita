    ?   My Spring Boot application uses a Spring profile to select implementation classes at runtime.
    ?   My `application.yaml` file uses the following property to select the Spring profile during the Maven build:
    ?   ```
    ?   spring:
    ?       profiles:
    ?           active: "@calycopis-platform@"
    ?   ```
    ?   How can I set the default Spring profile to use in the OCI container image generated by `spring-boot-maven-plugin`
    ?   and is there a way to override this at runtime by passing a parameter via the Docker run comand.

    >   ....
    >   ....
    >   Spring Boot defines a default profile that becomes active when no other profile has been explicitly selected, and spring.profiles.default lets you change its name.
    >   Then:
    >   ```
    >   docker run calycopis-broker:latest
    >   ```
    >   uses:
    >   ```
    >   docker
    >   ```
    >   whereas:
    >   ```
    >   docker run \
    >       -e SPRING_PROFILES_ACTIVE=openstack \
    >       calycopis-broker:latest
    >   ```
    >   uses:
    >   ```
    >   openstack
    >   ```
    >   instead.
    >   I think this is the better model for your case:
    >   ```
    >   spring:
    >       profiles:
    >           default: docker
    >   ````

    ?   Could I combine the default setting with a value in an optional config file provided at runtime ?

    >   Yes. A good pattern is:
    >   
    >   define a built-in default in application.yaml;
    >   optionally import an external config file at runtime;
    >   allow environment variables or command-line arguments to override both.
    >   
    >   Spring Boot’s external configuration system is designed for exactly this.
    >   For example, package this in your application:
    >   ```
    >   spring:
    >     profiles:
    >       default: docker
    >   
    >     config:
    >       import: optional:file:/config/calycopis.yaml
    >   ```
    >   Then if /config/calycopis.yaml is absent, the application starts normally and uses the docker profile.
    >   If the file exists, it can contain:
    >   ```
    >   spring:
    >     profiles:
    >       active: openstack
    >   ```

# Create our configuration files.
#[user@desktop]

    CONFIG_DIR=$(mktemp -d)

    cat > "${CONFIG_DIR}/admin.yaml" << EOF
calycopis:
    admin:
        username: $(pwgen 32 1)
        password: $(pwgen 32 1)
EOF

    cat > "${CONFIG_DIR}/database.yaml" << EOF
spring:
    datasource:
        url: jdbc:postgresql://postgres:5432/calycopis
        username: $(pwgen 32 1)
        password: $(pwgen 32 1)
        driverClassName: org.postgresql.Driver
        initialize: true
EOF

    cat > "${CONFIG_DIR}/spring.yaml" << EOF
spring:
    profiles:
        active: docker
EOF


    yq '.spring.datasource.username' \
       "${CONFIG_DIR}/database.yaml" \
       > "${CONFIG_DIR}/pgusername"

    yq '.spring.datasource.password' \
       "${CONFIG_DIR}/database.yaml" \
       > "${CONFIG_DIR}/pgpassword"


    echo ${CONFIG_DIR}
