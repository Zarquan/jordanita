    Using rules to add attribution.

        Gradually evolving into current form.
            * Source code

            AGENTS.md gets truncated.
            Need to aggregate a long history.

        Semantics
            * generated by ..

        Attribution

            Closed source uses copyright to control use
            Open source uses copyright to grant use

            AI agents - who owns the results
            * USA
            * UK
            * EU

            Linux foundation
            Developer Certificate of Origin (DCO).
            Relies on signed git commits.

            Current process
                Agent writes the code.
                Agent stages the changes.
                Agent writes the commit message.
                User approves the commit.

                Agent creates the pull request.
                User approves the merge.

            Harness engineering
                AGENTS.md
                + rules

            What next
            Loop engineering
                Agent writes the code.
                Agent commits the changes.
                Agent creates the pull request.
                Agent mergees the changes.

            What happens to the copyright ?
            What happens to the DCO ?
            What happens to the licensing ?

            No license is NOT open source free to use.
            Do we need a no-license license for AI in USA ?
            What happens to 50% human 50% agent ?
