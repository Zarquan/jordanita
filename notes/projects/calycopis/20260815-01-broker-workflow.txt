    Target:

        End to end build on the desktop.

    Result:

        Works on the desktop - fails if we try to launch it from inside a container.

        Building the schema components works on both desktop and container.
        Building the Java code for the broker works on both.
        Building the OCI image for the broker works desktop, fails in a container.
            The buildpack builder launches a container, which doesn't work from inside a container.
            The buildpack builder makes too many assumptions about the docker socket.

        Building the integration test container works on both.
            The build-tests script only works on desktop.

        Running the integration tests only works on desktop.
            Setting up the tests creates files on the host filesystem.
            In theory we could do this from inside a container
                We would need to allocate test space as a volume
                and use it to replace calls to mktemp
                and juggle the paths for inside and outside


        We can run end to end on desktop, and on GitHub workflow.
        However, the development container no longer works.
        If we want to isolate the build scripts we will need to create a virtual machine.

        Good enough for now.
        We can come back to look at other options later.
        Merge the branch.
