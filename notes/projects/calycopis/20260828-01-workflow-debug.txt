    So ALL the tests pass when run on local machine (directly on the host not in a container).
    Looks like there are issues with using /tmp in GitHub workflows.

    GitHub Actions: Using the Temporary Directory
    https://nesin.io/blog/temp-directory-path-github-actions

        Use $RUNNER_TEMP in shell scripts.
        Use ${{runner.temp}} in yaml workflows.

    Update run-tests.sh to use $RUNNER_TEMP

    TEMP_DIR=${RUNNER_TEMP:-$(mktemp -d)}
    echo $TEMP_DIR
