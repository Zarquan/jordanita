    STFC   => a+b

** User home
Will we want to give users a global 'home' (rw) directory that is shared across all sessions.
    GLOBAL_USER_HOME=/global/home/{username}

** User data
Will we want to give users a global 'data' (ro) directory that is shared across all sessions.
    GLOBAL_USER_DATA=/global/data/{username}

** Group data
Will we want to give groups a global 'data' (ro) directory that is shared across all sessions.
    GLOBAL_GROUP_HOME=/global/data/{groupname}

    South African system mounts data in predictable location in global group space
    Selecting a data product, it automagically appears unpacked at that location.
    /global/data/{groupname}/{productid}
    /global/data/{groupname}/CY3229_L_002_20160111

If a user is a member of more than one group, can they access data in both ?

    /global/data/group-A/...
    /global/data/group-B/...

How do we want to show the filesystem to the user ?
Is there a file explorer UI ?


** Temp data

Will we want to give users a 'temp' (rw) directory that is specific to each execution session.
    SESSION_DATA=/temp/{sessionid}

If we allocate session specific space, how long does it last after the session completes ?
Is it just a directory in the user's space, and it is up to them to manage the quota.
    SESSION_DATA=/global/data/{username}/{sessionid}

Does it make sense to the user to see it as one file system ?

    /global/{groupname}/data/{productid}
    /global/{groupname}/data/CY3229_L_002_20160111 <- ro mount of archive data

    /global/{groupname}/temp/{sessionid}
    /global/{groupname}/temp/06a7c888-51a7-47ac-a47a-fb4acf4148b6 <- rw mount of temp space

    /global/{groupname}/store/ <- rw mount of group's storage space

    /data  : read only access to the original data products.
    /temp  : Temp space for the execution to work in.
    /store : Storage space to put the user's results.

    What does an individual container execution see ?
    What uid:gid does an individual container execution use ?

    CANFAR does a lot of work to assign global uid:gid to all users.
    Access to directories is controlled by uid:gid.
    You can see /home/other, but you can't access it.

    If we simplify the container execution to a fixed uid:gid.
    How do we control what they can access.
    Do we only mount the relevant paths.
        /home/username is mounted
        /home/other is not mounted

    Where does the user put their results so that they can be used as inputs to another step ?
