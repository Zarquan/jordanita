In the spirit of the P3T team. If there is an existing RFC with several 
implementations behind it, we should at least evaluate it before we 
invent our wheel.

In addition to the Python framework that James cited, it looks like 
there is a growing ecosystem around creating and consuming RFC-9457 
messages.

We have been talking about standardising our error messages for a while, 
and at an initial glance RFC-9457 looks like it would be flexible enough 
to handle the range of things we need to cover, while still being 
structured enough for clients to handle.
