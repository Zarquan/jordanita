# Slide 4
# Claude agent identity

    Claude Code Co-Author Commits
    https://explainx.ai/blog/claude-code-commit-co-author-attribution-disable-guide-2026

While you remain the primary author, Claude Code automatically appends AI attribution metadata to the bottom of the commit message body by default.

        It injects a standard Git trailer that looks like this:

            ```
            Co-Authored-By: Claude Sonnet 4.6 <noreply@anthropic.com>
            ```

        Claude Code exposes direct control over this behavior via `settings.json`.

            ```
            {
              "attribution": {
                "commit": "Co-Authored-By: Claude Sonnet 4.6 <noreply@anthropic.com>",
                "pr": "🤖 Generated with [Claude Code](https://claude.ai/claude-code)"
              }
            }
            ```

# Slide 6
# We are here : Harness Engineering

    Harness Engineering
        Building the local environment or sandbox where an agent runs

        User asks the agent to make a plan.
        Agent writes the plan ....
        User reviews and agrees the plan.
        Agent writes the code ....

        Agent creates commit message with attribution.
        Agent waits for the human to approve the commit.
        User reviews and approves the commit.

        Agent commits the changes and creates pull request.
        User reviews and approves the pull request.

        Agent merges the pull request, updates clones and forks.

Human is still in the loop.
Agent writes code, human reviews and approves it.

# Slide 7
# What next : Loop engineering

    Loop engineering

        https://www.ibm.com/think/topics/loop-engineering

        Loop engineering is the practice of designing agentic workflows, or loops,
        that iteratively guide AI agents toward completing user-defined goals with
        minimal human intervention.

        Rather than require human prompting at every step, agent loops enable agents
        to dynamically act, observe, make decisions and iterate until a task is complete.

# Slide 8
# Copyright claims

    Loop engineering
    If we remove the human oversight, what happens to copyright ?

United States (USCO Rules)
https://pec.ac.uk/blog_entries/copyright-protection-in-ai-generated-works/

No Human Authorship = No Copyright:
The U.S. Copyright Office requires a human author for a work to qualify for copyright protection. Software generated entirely or predominantly by AI without substantial human creativity is placed into the public domain (meaning anyone can use, copy, or modify it).

United Kingdom (CDPA 1988 Rules)
    https://www.farrer.co.uk/news-and-insights/protecting-code-and-creativity-software-ip-rights-and-ai-generated-code/

Computer-Generated Works (Section 9(3)): The UK Copyright, Designs and Patents Act 1988 explicitly recognizes computer-generated works (CGWs) that have no traditional human author.

Authorship and ownership go to "the person by whom the arrangements necessary for the creation of the work are undertaken" (often the person or company that ran/directed the AI system).

        gov.uk Copyright and AI: Consultation
        https://www.gov.uk/government/consultations/copyright-and-artificial-intelligence/copyright-and-artificial-intelligence

# Slide 10
# Open source licenses

    TL;DR; AI generated code raises questions about copyright

    The copyright problem with AI-generated code
    https://allthingsopen.org/articles/copyright-problem-ai-generated-code-open-source-licenses

The more you lean on AI to write code for you, the less likely you are to hold copyright on the result.
In the extreme case of “vibe coding,” where you only describe the end product and the AI does all the work, you may not be able to claim any copyright at all.

And because open source licenses rely on copyright, you may not be able to place
a “vibe coded” project under an open source license, such as the GNU GPL.


Important to me because I am a strong advocate of copyleft licenses.

Everything I've produced in the last 20+ years has been published under the terms of the GPL.

That might no longer be possible ..

# Slide 11
# Summary

Copyright issues not withstanding, I think it is important that we declare how much of what we produce is AI generated.

    Good reasons for doing this:

        Measuring AI adoption

        Copyright and licensing

Geo-political factors
US bans code generated by Chinese models
China reciprocates and bans code generated by US models

Funding requirements
EU requires the use of EU models to qualify for funding

Security issues
Security vulnerability found in a model.
Malware injected by a specific harness.

        As a courtesy to our susbcribers:
            The people who receive our emails
            The people who use our code
            The people who attend our presentations

Using agent rules makes it automatic.
Minimal cost to the human, a few extra tokens.
