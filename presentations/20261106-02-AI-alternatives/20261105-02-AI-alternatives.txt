# Levels of adoption

    Prompt Engineering
        Crafting a single best instruction for an AI model

    Context Engineering
        Managing what information and data the model sees

    Harness Engineering
        Building the local environment or sandbox where an agent runs

        <-- we are here -->

    Loop Engineering
        Designing dynamic, repeating workflows that drive the agent toward completion

        <-- what happens next -->

# Slide 7
# Agent containerization

    DeepSeek Harness is run inside a Docker container.
    https://github.com/Zarquan/Lithosia-docker
    [github logo]
    [Docker-logo]

    Using volume mounts to control access to the host file system.
```
podman run \
    ....
    --volume "${PROJECT_PATH}:/Workspace"
    ....
```

    This isn't specific to DeepSeek, I ran Cursor in a container as well.

    General rule - don't give an AI agent unrestricted access to your home directoty.

    [DeepSeek logo] in a wire box
